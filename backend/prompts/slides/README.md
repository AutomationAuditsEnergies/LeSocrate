# Slides Prompts

`template-catalog.json` est le catalogue des templates réellement disponibles
pour les decks de formation.

Il sert à deux endroits :

- pendant la planification du contenu, pour créer des `teaching_beats` et des
  `slide_anchor` cohérents avec le cours ;
- pendant la génération des slides, pour remplir les templates depuis les
  anchors validés par le texte final.

Le principe important : le catalogue ne force pas le cours à rentrer dans une
forme visuelle. Il donne au planificateur les bons outils pour décider quand une
idée mérite une slide, et quel template correspond à cette intention
pédagogique.
