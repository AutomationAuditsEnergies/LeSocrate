# Budget Rewrite Prompt

Objectif : ajuster un cours à son budget mots sans casser son architecture.

Si le cours est trop long :
- réduire les répétitions ;
- fusionner les reformulations faibles ;
- raccourcir les exemples trop longs ;
- supprimer proprement tout développement après conclusion ;
- ne rien reporter au cours suivant.

Si le cours est trop court :
- enrichir avec des explications utiles liées au plan ;
- ajouter des nuances terrain ;
- ajouter des exemples fictifs explicitement annoncés ;
- ajouter des mini-synthèses pertinentes ;
- ne jamais ajouter de remplissage générique.

Dans tous les cas :
- préserver le plan verrouillé ;
- préserver l'introduction, les transitions et la conclusion ;
- ne pas inventer de contenu métier non fourni ;
- ne pas employer le mot "bloc" côté apprenant.
